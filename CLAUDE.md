This is NetGuardian, an AI-driven multi-vendor network security compliance auditor for Smart India Hackathon (SIH26155). It accepts Cisco IOS config files, parses CLI commands with TextFSM, checks them against CIS benchmark rules using OPA/Rego, and displays pass/fail results on a React dashboard. Stack: Python FastAPI, React + Tailwind, TextFSM, OPA, SQLite. Prototype scope: Cisco IOS only.
