This is NetGuardian, an AI-driven multi-vendor network security compliance auditor for Smart India Hackathon (SIH26155). It accepts Cisco IOS config files, parses CLI commands with TextFSM, checks them against 19 CIS benchmark rules with Python checks (OPA/Rego evaluation is planned post-prototype), and displays pass/fail results on a React dashboard. Stack: Python FastAPI, React + Tailwind, TextFSM, SQLite. Prototype scope: Cisco IOS only.
